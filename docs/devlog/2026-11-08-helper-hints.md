# 2026-11-08 — 헬퍼 안내 방식 변경: 첫 등장 한 줄 + 무기별 그림 카드

## 배경

전투 전 브리핑(패턴 11장 × 설명 문장)이 "글이 너무 많아 어지럽다"는 피드백. 네 가지 안(첫 등장 한 줄 / 그림 카드 / 실습형 / 혼합) 중 **혼합(D)** 선택.

## 변경

| 항목 | 내용 |
|---|---|
| 처음 접속 | 헬퍼 인사 세 줄 + "테스트 시작" |
| 패턴 첫 등장 | 0.7초(실제 시간) 동안 게임이 0.3배속 + 화면 아래 헬퍼 말풍선 한 줄 2.4초. 패턴마다 한 번 (이번 접속 동안) |
| 패턴 안내 (일시정지 메뉴) | 무기별 그림 카드 6장 (3×2): 무기 아이콘(게임 안 실루엣과 같은 모양) + 패턴 이름 + 패링 불가 표시 + 대응법 꼬리표 |
| 노이즈 준비 | 카드의 칸(무기·패턴 이름·대응법)마다 열쇠. `setCorrupted`로 맞지 않는 칸만 글리치 처리 (빨강·검정 어긋남 + 줄무늬 + 떨림). 실제 사용은 학습 단계 (변칙 패턴) |
| 실습형 튜토리얼 | 나중에 1막을 제대로 설계할 때 (이번 한 줄 대사를 재사용) |

## 아이디어 기록

**카드 노이즈 (사용자 아이디어)**: 변칙 패턴이 나올 때마다 헬퍼 카드에서 더 이상 맞지 않는 부분이 노이즈로 깨진다 → "헬퍼의 정석이 무너졌다"를 카드 하나로 보여줌. [학습 연출 ⑮](../design/learning-feedback.md#3-보여주는-방법)
