# 2026-11-07 — M1-2d 사망 시스템: 한 방 사망, 보호막, 체크포인트, 사망 지도, 미확인 → 관측

## 목표

"죽음 → 데이터"의 첫 고리. 많이 죽어도 지치지 않고, 죽을 때마다 무언가(정보)가 남게 한다.
설계: [학습 연출·사망 시스템 §5~6](../design/learning-feedback.md#5-사망-시스템)

## 구현

| 항목 | 내용 |
|---|---|
| 한 방 사망 | 보스의 모든 공격에 한 번 맞으면 쓰러짐. 설정 `oneHitKill`(false면 예전 체력 방식). 플레이어 체력 바 제거 |
| 보호막 | 목숨마다 1회, 자동. 맞으면 피해 없이 경직·밀려남 + "SHIELD BROKEN". 몸 둘레 점선 고리 + HUD 원. **포션은 완전히 제거** (상태·Q 입력·그리기·테스트) |
| 재시작 | 결과 화면까지 0.6초. R·버튼으로 바로 재시작 |
| 5단계 체크포인트 | 보스 체력 바 5칸(구분선), 한 칸 깎을 때마다 "CHECKPOINT SAVED n/4". 죽으면 저장된 칸 맨 위 체력으로 재개(▼ 표시). 클리어하거나 일시정지 메뉴 "처음부터 다시"면 초기화 |
| 모드 전환 (테스트용) | M: 체크포인트 ↔ 튜토리얼(처음부터). 나중에 막에 따라 자동 |
| 사망 기록 | 위치, 죽인 공격, 무기, 연속기 몇 번째 타, 보스 체력 비율, 직전 1초 움직임(0.05초 간격). 브라우저 저장소에 저장, 실패해도 게임 진행. 최대 500개. K: 초기화 |
| 사망 지도 | 결과 화면 "QA TELEMETRY · 버그 제보용 사망 데이터": 경기장 3×3, 이전 사망 회색 X + 옅은 궤적, 이번 사망 빨간 X + 진한 궤적 + 화살표. 사망 원인, 누적 통계(최다 공격·주 위치), 관측 패턴 목록. Tab: 크게 보기 |
| 미확인 → 관측 | 관측 안 된 패턴은 예고 단계의 바닥 범위를 숨기고 보스 위에 `UNKNOWN ???`. 맞거나(보호막·사망) 패링·대시로 피하거나 끝까지 버티면 "PATTERN LOGGED: 이름" → 다음부터 예고가 보임. 디버그 줄에서도 이름을 숨김 |

## 구조

| 파일 | 역할 |
|---|---|
| `run/Telemetry.ts` | 사망·관측 기록, 저장소(브라우저/메모리), 통계, 3×3 구역 (순수 로직) |
| `run/TrailRecorder.ts` | 최근 움직임 기록 → 이후 잔상 시스템의 녹화기로 확장 |
| `run/Checkpoint.ts` | 체력 단계 체크포인트, 재시작 모드 |
| `ui/DeathMap.ts` | 사망 지도 그리기 (HTML 캔버스) |
| `GameScene` | 씬이 재시작되어도 남는 값(기록·체크포인트·모드)은 씬 바깥에 둠 |

## AI 사용

- 브라우저 화면 확인: 이 작업 환경에는 Phaser 실행 파일이 없어 게임 전체는 못 띄움 → Phaser와 무관한 **결과 화면·사망 지도만 따로 headless Chrome으로 렌더링해 스크린샷 확인**
  - 발견: Tab 크게 보기에서 제목·버튼이 화면(540) 밖으로 넘침 → 지도 640×360으로 줄이고 크게 보기에서 제목 숨김 → 다시 확인
- 같은 순간 알림 두 개(PATTERN LOGGED + SHIELD BROKEN)가 덮어쓰는 문제를 코드 검토로 발견 → 줄바꿈으로 함께 표시
