# 2026-11-07 — M1-2b 전투 판정·피해·자세 게이지·결과 화면

## 목표

보스와 실제로 싸울 수 있는 상태: 맞히고, 맞고, 피하고, 패링하고, 쓰러지고, 다시 시작한다.

## 배경: "다크소울 같지 않다"는 피드백

2a 플레이 후 "아직 다크소울 보스 같지 않다"는 피드백. 원인 분석:

| 부족한 것 | 해결 시점 |
|---|---|
| 맞아도 피해가 없어 긴장감 0 | **2b (이번)** |
| 바닥 빨간 범위로 걸어서 피함 = MMO 방식. 다크소울은 몸동작을 읽고 타이밍에 구름 | 2c: 1막엔 "시뮬레이션 보조 표시", 각성 후 꺼짐 (스토리 장치) |
| 보스에게 몸과 무기가 없음 | 2c |
| 타격감·소리 없음 | 2b 일부(히트스톱·흔들림) + 2c(효과음) |
| 연속기·박자 변화 없음 | 2c |

결론: 3D는 증폭기이지 해결책이 아님. 2b → 2c("소울 느낌" 작업) → 3D 시험판 순서.

## 추가 반영: 움직이며 평타 (작업 중 요청)

|---|---|---|

| 3타 | 제자리 고정 | 무거운 마무리. 이후 "세 번째 칼날"이 노리는 리스크가 분명해짐 |

## 전투 규칙

| 항목 | 규칙 |
|---|---|
| 내 공격 | 판정 단계에서만, 한 번 휘두르면 한 번만 맞음. 점프 중인 보스는 맞지 않음 |
| 보스 공격 | 판정 단계에서만, 한 공격당 한 번만 맞음 |
| 대시 회피 | 무적 중이면 피해 없음. **무적이 끝났는데 아직 판정 안이면 맞음** (늦은 회피) |
| 패링 | 패링 판정 중 + 패링 가능한 공격 → 피해 없음, 보스 자세 +30, 보스 움찔(공격 끊김) |
| 패링 불가 공격 | 패링 중이어도 맞음 |
| 자세 게이지 | 내 공격 피해 × 0.6만큼 쌓임, 1.5초간 안 맞으면 서서히 감소. 가득 차면 **자세 붕괴 2초 + 받는 피해 2배** |
| 피격 | 0.35초 경직 + 반대쪽으로 밀려남. 하던 행동 끊김 (마시던 포션은 소모된 채 사라짐) |
| 몸 겹침 | 플레이어가 보스 몸을 통과하지 못함 |
| 타격감 | 히트스톱(내 공격 60ms, 패링 130ms, 피격 90ms, 자세 붕괴 160ms) + 화면 흔들림 |
| 결과 | "SIMULATION TERMINATED" / "SIMULATION COMPLETE" (시뮬레이션 설정에 맞춤), R 또는 버튼으로 재시작 |
