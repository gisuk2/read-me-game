## 목표

이동, 마우스 조준, 대시, 3타 공격, 패링, 포션, 체력·스태미나

## 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 대시 방향 | 이동키 방향, 없으면 마우스 방향 | 탑다운 액션에서 자연스러움. 보스 학습은 "보스 기준 방향"으로 기록하므로 영향 없음 |
| 구조 | `PlayerModel`(순수 로직) / `PlayerView`(그리기) / `InputReader`(입력) 분리 | 자동 테스트 가능, 이후 봇 플레이어가 같은 모델을 사용 |
| 수치 | `src/config/balance.ts` 한 곳에 모음 | 플레이테스트 조정을 쉽게 |
| 물리 엔진 | 사용하지 않음 | 판정이 단순(원·부채꼴)하고, 순수 로직으로 두어야 테스트가 쉬움 |
| 공격 콤보 | 공격 중 재입력을 "예약" → 경직 진입 순간 다음 타 | 입력 타이밍이 조금 빨라도 자연스럽게 이어짐 |

## M1-1b — 첫 플레이 피드백 반영

### 피드백

| 피드백 | 반영 |
|---|---|
| 누르면 바로 나가는 딱딱함, 모션이 필요 | 검 모션(당기기 → 휘두르기 → 머무름), 방패 모션(펼침 → 내려감), 포션 모션(병 + 원형 진행 게이지), 대시 잔상 |
| 1·2·3타 간격이 너무 짧음 | 준비/판정/경직: 1타 220/100/300, 2타 200/100/320, 3타 380/120/480 (기존 대비 약 2배) |
| 꾹 누르면 계속 공격? | 지원. 누르고 있으면 다음 타로 이어지고, 경직 전에 손을 떼면 그 타에서 멈춤 |
| 체력·스태미나는 게이지바로 | HUD 추가 (체력 바, 스태미나 바, 포션 아이콘). 스태미나 부족 시 바가 깜빡임 |
| 대시로 후딜 캔슬? | 경직 후반 60%만 캔슬 가능 (`attackDashCancelFrom: 0.4`). 준비·판정은 여전히 취소 불가 |

### 디자인 판단

- **꾹 누르기와 "세 번째 칼날"의 관계:** 꾹 누르는 습관이 있으면 항상 3타까지 치게 되고, 보스가 그 습관을 학습한다. 대응법은 "2타에서 손 떼기"가 된다.
- **캔슬을 후반부로 제한한 이유:** 전체 캔슬을 허용하면 공격의 리스크가 사라져 보스의 반격 패턴이 약해진다. 캔슬 가능 시점에 검이 내려가는 모습으로 보여준다.
- **모션은 모델의 "단계 + 진행률"로 계산:** 화면의 움직임과 실제 판정 타이밍이 항상 일치한다.

## M1-1c — 콤보가 경직을 건너뛰는 버그 수정

### 피드백

> 꾹 누르면 너무 빨리 넘어간다. 2타에서 3타로 가는 게 거의 캔슬되어 나가는 느낌.

### 원인 (AI 설계 오류)

다음 타를 **경직이 시작되는 바로 그 순간**에 내보내도록 설계되어 있었다. 예약하거나 꾹 누르고 있으면 1타·2타의 경직이 통째로 건너뛰어졌다. 테스트도 이 동작을 "정상"으로 검사하고 있어서 잡아내지 못했다.

### 수정

| 항목 | 내용 |
|---|---|
| 연결 시점 | 타마다 `comboLinkFrom`(경직 대비 비율)을 두고, 그 지점이 지나야 다음 타가 나감 |
| 값 | 1타→2타 0.5 (150ms 멈춤), 2타→3타 0.7 (224ms 멈춤, 마무리타 전 한 박자) |
| 우선순위 | 캔슬 구간(경직 40% 이후)에서 대시를 누르면 다음 타 예약보다 대시가 우선 |
| 디자인 연결 | 2타→3타 사이의 한 박자는 이후 보스의 "세 번째 칼날"이 노리는 틈이 된다 |

### 검증 `[검증됨]`

| 검증 | 결과 |
|---|---|
| 타입 검사 | 통과 |
| 테스트 | 32개 통과 (신규 4, 기존 콤보 테스트 3개를 새 기준으로 수정) |
| **원래 버그 재현** | "경직 시작 즉시 다음 타"로 되돌리면 → 4개 실패 (이번 버그를 이제 테스트가 잡음) |
| 우선순위 뒤집기 | 다음 타를 대시보다 먼저 처리하게 바꾸면 → 1개 실패 |

### 배운 점

- 테스트가 통과해도 **테스트가 검사하는 기준 자체가 틀릴 수 있다.** 테스트는 "코드가 의도대로 동작하는가"만 확인하고, "의도가 맞는가"는 직접 플레이해야 알 수 있다.
- 버그를 고칠 때는 **그 버그를 재현하면 실패하는 테스트**를 같이 넣는다 (회귀 테스트).
