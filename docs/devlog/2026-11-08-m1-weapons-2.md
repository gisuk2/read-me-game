## 구조

| 항목 | 내용 |
|---|---|
| `combat/Projectiles.ts` | 날아가는 물체 (순수 로직): 이동, 경기장 밖 제거, 플레이어 판정(무적 통과 / 패링 튕겨내기 / 맞음), 튕긴 탄의 보스 판정 |
| 원거리 타 | 타 설정에 `fire` → 판정 순간 보스가 `fire` 이벤트, 씬이 물체를 만듦. 예고는 조준선(경기장 끝까지), **근접 판정 없음** (`melee: false`) |
| 지연 내려찍기 | 원형 패턴에 `hang` 구간 (공중에서 멈칫) |
| 되감기 | 날아가는 물체도 되감기 대상에 포함 |
| 헬퍼 브리핑 | 11장 → 2열 카드. 패턴별 파훼법 대사는 데이터 파일 (빠지면 타입 검사가 잡음) |
| 무기 실루엣 | 총 = 짧은 몸통 + 가는 총열 + 손잡이 / 맨손 = 양쪽 주먹. 사격은 총을 조준 방향으로, 지면 파동은 해머를 치켜들었다 내리침 |
| 물체 그리기 | 보스 탄 = 검은 원 + 꼬리 / 튕긴 탄 = 흰 원 / 충격파 = 붉은 막대 (패링 불가 = 빨강) |
