# 2026-11-07 — 무기 1부: 보스 무기 교체, 쌍검 7연타

## 목표

보스가 패턴마다 다른 무기를 들어서, **실루엣만 봐도 다음 공격 계열이 읽히게** 한다. 다음 단계(2d)의 한 방 사망·미확인 패턴(예고 없이 몸동작만)의 전제 조건.

## 구현

| 항목 | 내용 |
|---|---|
| 무기 | 대검(휘두르기·회전), 창(찌르기), 해머(내려찍기), 쌍검(연속 베기). 시작 무기 = 대검 |
| 교체 | 고른 패턴의 무기가 지금 무기와 다르면 `swap` 상태 0.4초 → 끝나면 새 무기로 다시 다가가기. 교체 중에는 공격하지 않음 (작은 빈틈) |
| 교체 취소 | 교체 중 자세가 무너지면 교체 취소, 이전 무기 유지 |
| 교체 연출 | 앞 절반: 이전 무기가 깜빡이며 사라짐 / 뒤 절반: 새 무기가 옆으로 어긋난 채 나타남 (글리치) |
| 실루엣 | 대검 = 굵은 날 + 가드 / 창 = 가늘고 긴 자루 + 삼각 날 / 해머 = 자루 + 사각 머리 / 쌍검 = 짧은 날 양손 |
| 쌍검 7연타 | 좌우 번갈아 돌진(타당 30, 마지막 50). 4타 뒤 짧은 멈칫 → 5타 지연, 7타는 크게 지연. 타당 피해 12. 7번 다 패링하면 스태미나 126 필요 (최대 100) → 뒤로 빠지기 유도 |
| 디버그 표시 | 보스 줄에 현재 무기, 교체 중이면 "무기 교체 대검 → 창" |

## 테스트 변경

- 기존 2개 수정 (의도된 동작 변화): 내려찍기 테스트는 해머로 바꿔 든 뒤 예고 시작 / 관찰 종료 후 상태는 "다가가기 또는 무기 교체"
- 임시 실행기에 없는 `toContainEqual` 대신 `some()`으로 작성
