# 2026-11-07 — 조정 2: 무기별 이동 속도, 범위 +20%, 쌍검 4번 베기 + 마무리 돌진

| 항목 | 내용 |
|---|---|
| 무기별 이동 속도 | 쌍검 100 / 창 80 / 대검·해머 65. 관찰 중 옆으로 돌기·물러나기도 같은 비율 |

| 마무리 돌진 | 예고를 시작한 자리에서 뻗는 직사각형 240×70. 판정 0.16초 안에 200 돌진. 조준을 일찍 고정(예고의 35%)해 범위를 오래 보여줌. 두 날을 앞으로 모으는 자세 |

## 구조 변경

- **타별 카테고리**: 한 패턴 안에서 타마다 패링 가능 여부를 바꿀 수 있음 (`step.category`)
- **타별 모양**: `dashRect` = 출발 지점부터 뻗는 직사각형 (지나가는 길 전체가 판정)

## 결정 이유

베기는 패링하거나 뒤로 빠지고, 돌진은 옆으로 피한다 → 한 패턴 안에서 정답이 나뉘어 "읽는 맛"이 생김.
