## 구조 변경

- 플레이어 공격이 판정 모양(`shape`)을 직접 알려준다 → 판정 시스템은 부채꼴·직사각형을 구분하지 않고 그대로 검사

## AI 사용

- 테스트 실수 3건 (코드 문제 아님): 3타까지 잇는 도우미가 콤보를 이어가지 못함 / 찌르기 시작 시점 측정이 한 프레임 늦음 / 수정 중 기존 테스트 한 줄을 잘못 바꿈 → 기존 테스트 파일과 비교해서 되돌림 확인
