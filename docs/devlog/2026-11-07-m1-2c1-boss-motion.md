## 구현

| 항목 | 내용 |
|---|---|
| 스태미나 | 회복 40 → **20/초**, 패링 소모 8 → **18** |
| 카테고리 | 패턴에 `category` (normal/heavy). 패링 가능 여부는 카테고리로 정해짐 |
| 타(step) 구조 | 한 패턴 = 1타 이상. 타마다 예고·추적 비율·돌진 거리·판정·경직 |
| 조준 추적 | 예고 앞부분(`trackRatio`)은 플레이어를 따라 돔 (초당 4 라디안 제한), 이후 고정. 내려찍기는 착지 지점이 따라옴 |
| 돌진 | 판정 순간 `lungeDistance`만큼 앞으로. **예고 범위는 처음부터 돌진한 위치에 그림** (예고 = 판정) |
| 연속 베기 | 4연타, 타마다 돌진, 마지막 타는 박자를 늦춤. 일반 카테고리 |
| 연속기 패링 | 중간 타 패링 = 자세 게이지만 쌓이고 계속 몰아침 / 마지막 타 패링 = 움찔 |
| 끊는 지점 | `cancelAfterHits: 2` → 2타 이후 틈에서 `cancelCombo(next)` 가능. 학습 단계용 자리 |
| 몸짓 (화면) | 보스 무기: 휘두르기 = 뒤로 젖힘(연속 베기는 좌우 번갈아), 찌르기 = 뒤로 당겼다 뻗음, 회전 = 감아 돌림, 내려찍기 = 치켜듦. **강패턴은 준비 중 무기가 붉게 빛남** |
| 고정 신호 (화면) | 추적 중 바닥 예고는 가늘고 옅게 → 고정되면 굵고 진하게 |

## AI 사용

- 요청: 위 계획(승인됨) → **사용**
- 내가 쓴 테스트의 실수 1건: "끊고 휘두르기로 이어가기" 테스트에서 설정에 휘두르기를 넣지 않아 실패 → 코드가 아니라 테스트를 고침 (실패 원인을 확인한 뒤 수정)
- 임시 테스트 실행기에 `toBeLessThanOrEqual`이 없어 추가 (실제 Vitest에는 있음)
