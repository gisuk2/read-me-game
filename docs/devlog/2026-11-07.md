## 2. M0 세팅

- 목표: 개발 환경과 저장소 뼈대
- AI 사용: 프로젝트 설정 파일, 확인용 씬(사각형 WASD 이동), 테스트 예제, 배포 워크플로 작성 요청 → 사용
- 원리 메모
  - 게임 루프: Phaser가 매 프레임 `update(time, delta)`를 호출한다.
  - 프레임 독립 이동: 속도 × (delta / 1000) → 프레임 속도와 무관하게 같은 속도.
  - 대각선 정규화: 방향 벡터 길이를 1로 맞춰 대각선 이동이 빨라지지 않게 한다.
- 결정: 라이브러리 버전을 미리 적지 않고 설치 시점 최신 안정 버전을 받아 기록한다 (환각 방지).
- 결정: `npm install`은 Windows에서 직접 실행 (원격 리눅스 환경에서 설치하면 일부 빌드 도구가 리눅스용으로 설치될 수 있음).
- 실행 결과 `[검증됨]`
  - `npm test`: 4개 테스트 통과
  - `npm run typecheck`: 오류 없음
  - `npm run dev`: Vite 개발 서버 실행
- 실패 / 배운 점
  - 원격 도구는 `.github` 폴더에 쓸 수 없음 → `_setup/`에 두고 직접 옮김
  - 설치된 버전이 Phaser 4, TypeScript 7, Vite 8, Vitest 5 → AI가 아는 것보다 새 메이저 버전. Phaser 3 방식으로 쓴 코드(`import Phaser from 'phaser'`)는 타입 검사 통과
- 소요 시간: 예상 _h / 실제 _h
