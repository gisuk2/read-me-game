## 1. 한 줄 요약

> 가상공간 전투 시뮬레이션의 베타 테스터가 된 평범한 사람. 친절한 안내 AI **"헬퍼"**에게 로봇과 싸우는 법을 배우지만, 어느 순간 로봇이 각성하고 **헬퍼의 말을 따를수록 죽는다.** 헬퍼의 지시를 거역하는 순간, 진짜 게임이 시작된다.

## 2. 설정

| 항목 | 내용 |
|---|---|
| 세계 | 가상공간 전투 시뮬레이션. 흰 공간과 기하학 도형으로 이루어진 훈련장 |
| 플레이어 | 평범한 사람. 아르바이트로 신청한 **베타 테스터** |
| 목적 (표면) | 시뮬레이션의 전투 로봇을 상대로 베타 테스트 진행 |

시뮬레이션이라는 설정이 설명해 주는 것:

| 게임 요소 | 설정상 이유 |
|---|---|
| 미니멀 흑백 그래픽 | 가상공간. 3D로 가도 같은 설정 |
| 죽어도 다시 시작 | "시뮬레이션 리셋" |
| HUD·예고 표시 | 시뮬레이션의 시스템 UI |
| 각성 연출 | 화면 노이즈, 글리치, UI 오류 |

## 3. 등장인물

### 헬퍼 (Helper)

| 항목 | 내용 |
|---|---|
| 정체 (표면) | 시뮬레이션의 **안내 AI**. 친절하고 성실한 튜토리얼 담당 |
| 이름의 이중 의미 | **도우미**(helper) / 게임 은어로 **핵 프로그램**(헬퍼) → 처음부터 정체가 이름에 적혀 있던 떡밥 |
| 진실 | **처음부터 해킹당해 있었다.** 헬퍼 자신은 몰랐다 (해석 A) |
| 해킹의 방식 | 해커가 헬퍼의 지시 내용을 몰래 바꿔, 플레이어를 **예측 가능한 행동으로 길들임** |
| 감정선 | 친절한 선생님 → 진심으로 혼란 → 자신이 이용당했음을 알게 됨 → 플레이어의 진짜 동료 |

### 로봇 (보스)

| 항목 | 내용 |
|---|---|
| 외형 | 검은 육각형 (3D라면 육각기둥). 기하학적 존재 |
| 표면 | 베타 테스트용 전투 로봇. 정해진 패턴으로 움직임 |
| 각성 이후 | 플레이어의 습관을 학습해 역이용. 그 습관은 헬퍼의 지시로 만들어진 것 |

### 해커

| 항목 | 내용 |
|---|---|
| 정체·동기 | **미정** (아래 9장 후보) |
| 등장 방식 | 직접 등장보다는 흔적(글리치, 로그 조각)으로 존재를 암시 |

## 4. 구성

| 구간 | 내용 | 헬퍼 | 로봇 |
|---|---|---|---|
| **프롤로그** | 시뮬레이션 접속, 베타 테스트 안내 | 친절한 첫인사, 조작 안내 | 대기 |
| **1막: 튜토리얼** | 패턴과 대응법을 차근차근 배움 | 선생님. 패턴마다 피하는 법·파훼법을 지시 | 정직한 패턴 |
| **각성** | 로봇이 멈칫, 시뮬레이션에 노이즈 | "어…? 저건 내가 아는 패턴이 아니야!" (진짜 혼란) | 첫 역이용 |
| **2막: 죽음의 반복** | 헬퍼 말대로 하면 계속 죽음 | 계속 같은 지시 ("오른쪽으로 피하세요!") | 헬퍼 지시를 따르는 습관을 역이용 |
| **전환점** | 플레이어가 **헬퍼의 지시를 거역하고 살아남음** | 혼란 | 예측이 빗나감 → 큰 빈틈 |
| | **이 순간 게임 제목이 처음 화면에 뜸** — 진짜 게임의 시작 | | |
| **3막: 본게임** | 진짜 대결. 예고 축소, 탄막, 방패 탈취 | 혼란 속에서 분석을 시작 → 분석 파트너 | 플레이어 자신의 습관을 학습 |
| **반전** | 헬퍼가 해킹당했던 사실이 드러남 | 자신이 이용당했음을 알게 됨 | |
| **최종: 거울** | 로봇이 플레이어처럼 싸움 | (미정) | 거울 페이즈 |
| **엔딩** | **미정** | | |

## 5. 전환점 설계: "거역하는 순간"

이 게임의 핵심 장면.

```
2막: 헬퍼 "오른쪽으로 피하세요!" → 플레이어가 따름 → 로봇이 오른쪽을 노림 → 죽음
     (반복될수록 힌트가 강해짐)
전환점: 플레이어가 왼쪽으로 피하거나 패링 → 로봇의 예측이 빗나감 → 살아남음
     → 노이즈가 걷히고 게임 제목이 뜸
```

| 원칙 | 내용 |
|---|---|
| 공정성 | 헬퍼 지시를 따른 행동만 막힌다. **다른 선택지(반대 방향, 패링)는 항상 살 수 있다** |
| 짧은 재시작 | 2막에서 죽으면 **각성 직후 체크포인트**에서 다시 시작 (전투 처음부터가 아님) |
| 단계적 힌트 | 1회차: 헬퍼가 당황 / 2회차: 로봇 대사 "…또 그 목소리를 따르는군." / 3회차: 헬퍼 음성에 노이즈, 지시 글자가 깨짐 |
| 기술적 정합성 | 로봇은 실제로 "헬퍼 지시를 따르는 습관"을 학습한다. 연출이 아니라 학습 결과 |

### 기술 요구사항

| 기능 | 내용 | 시점 |
|---|---|---|
| 헬퍼 지시 시스템 | 패턴마다 헬퍼가 대응법을 말함 (데이터로 관리) | M1 6단계 |
| 순응도 기록 | 플레이어가 지시를 따랐는지 기록 → 로봇의 학습 데이터 | M1 4~6단계 |
| 전환점 판정 | "지시를 거역했고 살아남음" 이벤트 → 막 전환 | M2 |
| 체크포인트 | 막 단위 재시작 | M2 |
| 글리치 연출 | 화면 노이즈, 글자 깨짐 | M2 |

## 6. 떡밥 목록

반전을 알고 나면 다시 보이는 단서. **1막부터 조금씩 심어 둔다.**

| 떡밥 | 내용 | 등장 |
|---|---|---|
| 이름 | "헬퍼" = 도우미 / 핵 프로그램 | 처음부터 |
| 미세한 글리치 | 헬퍼 대사에서 아주 가끔 글자가 한 프레임 깨짐 → 해커가 끼어든 흔적 | 1막부터 |
| 알 수 없는 것을 앎 | 헬퍼가 아직 안 나온 패턴 이름을 먼저 말했다가 정정 | 1막 후반 |
| 치우친 조언 | 헬퍼는 늘 같은 쪽(예: 오른쪽)을 권함. 사망 리포트 통계에 드러남 | 1막~2막 |
| 시스템 로그 조각 | 일시정지 메뉴·사망 화면 구석에 `helper.exe — 권한: 관리자(?)` | 2막부터 |

## 7. 죽음 규칙

[전투 시스템 공정성 원칙](combat-system.md#8-공정성-원칙) 9번을 이 스토리에 맞게 수정:

> **죽음은 스토리 장치로 쓸 수 있다. 단, 재시작은 짧게 하고 매번 힌트를 더 준다.**

- 1막: 튜토리얼 중 죽으면 해당 패턴 연습부터 재시작
- 2막: 각성 직후 체크포인트
- 3막 이후: 막 단위 체크포인트

## 8. 범위

| 마일스톤 | 스토리 범위 |
|---|---|
| M1 | 프롤로그(간단), 1막 튜토리얼, 각성, 첫 죽음. 헬퍼 기본 대사·지시, 떡밥 일부(이름, 미세 글리치) |
| M2 | 2막 죽음 반복 → 전환점(제목 등장), 3막, 반전, 거울, 엔딩 |

반전을 위해 나중에 1막을 다시 고치지 않도록, **떡밥은 M1부터 심는다.**

## 9. 미정 사항

| 항목 | 후보 |
|---|---|
| 해커의 정체·동기 | ① 테스터의 전투 데이터를 몰래 수집해 판매 ② 로봇 AI를 무기화 ③ 시뮬레이션 회사 내부자의 고발 (일부러 문제를 드러내려 함) |
| 반전 이후 헬퍼의 역할 | 진짜 동료로서 최종전 지원 / 스스로 해킹을 끊고 사라짐 |
| 엔딩 | 로봇을 이기고 시뮬레이션 탈출 / 해커와의 대면 / 헬퍼와의 마지막 대화 |
| 로봇의 이름 | 미정 |
| 게임 제목 | 가칭 "READ ME" (전환점에 처음 등장) |
