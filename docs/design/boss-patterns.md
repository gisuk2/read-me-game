## 0. 패턴 카테고리

| 분류 | 성격 | 정답 행동 | 목표 수 |
|---|---|---|---|
| **일반** | 패링 가능. 무기·탄환 공격 | 패링 / 회피 | 6 |
| **강** | 패링 불가. 몸 전체·낙하·에너지 | 회피 / 거리 | 6 |
| **페이즈** | 기믹형. 맵 전체 사용, 파훼법 있음. 기본형 + 변칙형 | 기믹 풀기 | 10 |

학습 패턴(§4)은 이 카테고리 위에 얹히는 변형이다.

### 0.1 패링 가능/불가 기준

| 기준 | 내용 |
|---|---|
| 물리적 직관 | "칼로 막을 수 있나?" 무기 베기·찌르기·날아오는 물체 = 가능 / 몸 전체·낙하·땅을 타고 오는 것·에너지 = 불가 |
| 다른 대응 강제 | 불가 공격마다 정답 행동이 하나씩 있어야 한다 (막을 수도 피할 수도 없는 공격 금지) |
| 위험도와 보상 | 패링 보상이 크므로, 패링 가능 공격은 빠르거나 박자 읽기가 어려워야 한다 |
| 일관성 | 패링 불가 신호(바닥 이중 점선 + 몸 신호)는 예외 없이 같은 뜻 |
| 학습 재료 | 패링 빈도 자체가 데이터. 기본 규칙이 확실해야 나중의 페이크가 의미 있다 |

### 0.2 무기

보스는 패턴마다 정해진 무기를 쓰고, 다른 무기가 필요하면 **바꿔 든다** (0.4초, 글리치 연출 = 시뮬레이션이 무기 데이터를 다시 불러오는 느낌). 실루엣만 봐도 다음 공격 계열이 읽히는 것이 목적이다 (한 방 사망의 공정성, 헬퍼 브리핑의 "무기를 보면 공격이 보인다"). 바꾸는 순간은 작은 빈틈이다.

| 무기 | 실루엣 | 패턴 |
|---|---|---|
| 대검 (느림 65) | 굵고 긴 날 + 가로 손잡이 | 휘두르기, 회전베기, 추격 베기 |
| 창 (중간 80) | 가늘고 아주 긴 자루 + 삼각 날 | 3연속 찌르기 |
| 해머 (느림 65) | 자루 + 큰 사각 머리 | 내려찍기, 지연 내려찍기, 지면 파동 |
| 쌍검 (빠름 100) | 짧은 날 양손 | 연속 베기 (4번 베기 + 마무리 돌진) |
| 총 (75) | 짧은 몸통 + 가는 총열 | 사격 |
| 맨손 (빠름 90) | 양쪽 주먹 | 잡기, 몸통 돌진 |
| 페이즈 전용 (예정) | | 기믹마다 |

학습 단계 후보: "이 플레이어에게 잘 먹힌 무기를 더 자주 든다".

### 0.3 일반·강 목록

| 일반 (패링 가능) | 상태 | 강 (패링 불가) | 상태 |
|---|---|---|---|
| 휩쓸기 | ✅ 2a | 회전베기 | ✅ 2a |
| 3연속 찌르기 (창, 세 번째 지연) | ✅ | 내려찍기 | ✅ 2a |
| 연속 베기 (쌍검 4번 베기 + 마무리 빠른 돌진. 베기는 패링 가능, **돌진만 패링 불가** = 타별 카테고리) | ✅ | 지연 내려찍기 (해머, 공중에서 멈칫하며 따라옴) | ✅ |
| 사격 (총 2발, **패링하면 탄이 보스에게 되돌아감**) | ✅ | 지면 파동 (해머, 직선 충격파) | ✅ |
| 추격 베기 (대검 돌진 3연속, 마지막 늦은 박자) | ✅ | 잡기 (맨손, 짧고 빠름, 옆으로) | ✅ |
| (미정) | | 몸통 돌진 (맨손, 긴 일직선) | ✅ |

**연속 베기 → 학습 연결:** 연속 베기에는 "도중에 끊고 다른 기술로 넘어가는 지점"을 둔다. 학습 단계에서 "연속 베기 때 뒤로 빠지는 습관 → 2타 후 끊고 원거리 탄환"을 끼워 넣는다. 탄환은 패링 가능하므로 읽힌 플레이어도 다시 대응할 수 있다.

### 0.4 페이즈 패턴 후보

페이즈가 시작되면 카메라가 플레이어 근접 → **맵 전체로 줌아웃**하고 기믹이 나온다. 1막에서는 헬퍼가 파훼법을 알려주고, 각성 후 변칙형은 헬퍼 말대로 하면 죽는다 (헬퍼 배신 연출).

| # | 기믹 | 파훼 | 변칙형 예시 |
|---|---|---|---|
| 1 | 과부하 파동 + 스태미나 봉인 | 기둥 뒤에 숨기 | 기둥이 하나씩 부서짐 |
| 2 | 순차 레이저 | 박자 맞춰 대시 | 박자가 갑자기 엇갈림 |
| 3 | 바닥 붕괴 | 안전 구역으로 | 안전 구역이 거짓 표시 |
| 4 | 장판 | 장판 밖에 있기 | 장판을 밟아야만 생존 |
| 5 | 환영 분신 | 진짜 찾아 공격 | 진짜가 공격 중에 바뀜 |
| 6 | 탄막 | 빈틈 찾기 | 빈틈이 가짜 |
| 7 | 스킬 봉인 | 봉인 동안 버티기 | 봉인된 행동을 써야 풀림 |
| 8 | 방패 뺏기 | 방패 되찾기 | 되찾는 길이 함정 |
| 9 | 좁혀오는 벽 | 출구 찾기 | 출구 여러 개, 하나만 진짜 |
| 10 | 추적 폭탄 | 보스 쪽으로 유도 | 유도하면 폭발 범위 확대 |

| 항목 | 결정 |
|---|---|
| 공통 시스템 | 카메라 전환, 장애물·엄폐 판정, 지속 장판, 상태 이상(봉인), 분신, 탄환 |
| 순서 | 3D 시험판으로 2D/3D 결정 후 → 페이즈 전환 + 기믹 2~3개 → 재밌으면 10개로 확장 |
| 체크포인트 | 기믹 시작 시점 = 저장 지점 ([학습 연출 §5.2](learning-feedback.md#52-재시작-지점)) |

## 1. 핵심 원리

모든 학습 패턴은 같은 구조다.

```
상황(조건)  →  플레이어의 행동
"보스 빈틈"  →  "3타까지 공격"
```

보스는 **"이런 상황에서 이 사람은 무엇을 하는가"**를 센다. 어떤 상황을 관찰할지가 곧 게임 디자인이다 (AI 용어로 특징 설계, feature engineering).

### 1.1 "그냥 공격 바리에이션 아냐?" 문제

반응이 몇 가지로 정해져 있으면 플레이어는 학습과 "공격 변형 2~3개"를 구별할 수 없다. 학습이 **느껴지지 않으면 없는 것과 같다.** 그래서 모든 학습 패턴은 아래 중 최소 하나로 학습을 증명한다.

| 증명 방식 | 내용 |
|---|---|
| 인과 | 내가 바꾸면 보스도 바뀐다. 한 번도 안 한 행동은 역이용당하지 않는다 |
| 구체적 기억 | 회차·수치가 들어간 대사 ("세 번째. 늘 세 번째였지.") |
| 연속값 개인화 | 정해진 변형이 아니라 학습값으로 공격을 조정 (예: 지연 시간 = 내 평균 패링 타이밍 + α) |
| **잔상** | 내 실제 과거 움직임을 재생 (§2) |
| 거울 | 보스가 내 방식으로 싸움 (§4.5) |

## 2. 잔상 시스템 (대표 시스템)

**보스가 예측한 나 = 녹화된 내 실제 궤적.** 정형화된 "왼쪽 대시"가 아니라 잡무빙까지 그대로 재생되므로, 스크립트로는 만들 수 없는 학습의 증거가 된다.

### 2.1 동작

```
[녹화] 패턴의 기준 시점(예고 시작)부터 정해진 구간 동안
       플레이어 상태(위치, 방향, 행동)를 0.05초마다 기록
[저장] 패턴 종류별로 궤적 목록을 쌓음
[재생] 같은 패턴에서 보스가 멈칫할 때, 궤적 하나를 반투명 실루엣으로 재생
[공격] 보스는 잔상이 도착하는 지점을 공격
```

### 2.2 설계 결정

| 항목 | 결정 |
|---|---|
| 재생 위치 | **상대 위치**: 궤적 모양은 그대로, 지금 내 위치에서 출발하도록 이동·회전 (보스 기준 방향 정렬) |
| 녹화 구간 | 패턴마다 고정된 기준 시점에서 시작 (궤적끼리 비교 가능하도록) |
| 표시 | 실제 플레이어와 확실히 구별: 회색 반투명 + 점선 외곽 |
| 데이터 없음 | 잔상도 없고 보스는 멈칫하지 않음 (1막의 평범한 보스) |
| 빗나감 | 매번 다르게 움직이면 잔상이 빗나감 → 예측 불가능함에 대한 정당한 보상 |

### 2.3 궤적 선택 로드맵 (AI 고도화)

| 단계 | 선택 방법 | 설명 |
|---|---|---|
| M1 | 가장 최근 궤적 | "방금 전 판의 나" |
| M3 | 대표 궤적 (medoid) | 다른 궤적들과의 평균 거리가 가장 짧은 궤적 = "평소의 나" |
| M4 | 궤적 클러스터링 | 비슷한 궤적끼리 묶어 습관 유형 발견 (궤적 비교에 DTW 사용 검토) |
| M5 (도전) | 시퀀스 예측 모델 | 작은 시퀀스 신경망으로 다음 움직임 생성 |

### 2.4 연결

| 연결 | 내용 |
|---|---|
| 예고 | 잔상이 가는 곳 = 공격 지점. 습관에서 벗어나야 산다 |
| 난이도 | 막이 진행될수록 잔상 표시 시간을 줄임 (§3) |
| 역이용 | 다른 궤적을 연습해서 가짜 습관을 심을 수 있음 |
| 사망 리포트 | 보스의 예측(잔상)과 실제 움직임을 겹쳐 재생 + 예측 정확도 |
| 거울 페이즈 | 보스가 내 궤적을 직접 따라 움직임 |
| 데이터 | 녹화 궤적이 M4~M5 학습 데이터가 됨 |

## 3. 역이용 예고 설계

예고 없이 피하라는 건 반칙이고, 친절한 전용 색 예고는 긴장감을 없앤다. 그래서 **전용 색 예고는 쓰지 않는다.** 대신:

```
멈칫 + 시선  = "지금 너를 읽었다" (읽었다는 신호)
잔상         = 어디를 노리는지 (내 습관 그 자체가 예고)
```

### 3.1 막별 예고 축소 ("가르쳐 놓고, 빼앗는다")

| 단계 | 예고 | 플레이어가 배우는 것 |
|---|---|---|
| 2막 첫 등장 | 멈칫 + 시선 + 잔상(길게) + 빨간 범위(충분한 시간) | "멈칫 = 나를 노린다" |
| 3막 초반 | 멈칫 + 시선 + 잔상(짧게) + 빨간 범위(짧은 시간) | 반응 속도 |
| 3막 후반 | 멈칫 + 시선 + 잔상(아주 짧게), 범위 표시 없음 | 내 습관 + 보스 몸짓 읽기 |
| 항상 | 비싼 보험: 완벽 패링, 보스 관통 대시 (스태미나 대량 소모) | 실력으로 돌파하는 길 |

목표 지표 예시 `[추정]`: 역이용 첫 회피 성공률 약 30%, 개념 이해 후 약 70%.

### 3.2 보류 아이디어: 승부차기 구조

멈칫 중 플레이어의 움직임까지 예측에 반영 → 먼저 움직이면 정보를 주고, 기다리면 정보를 숨긴다. 잔상 시스템과의 조합을 M3 이후 검토.

## 4. 패턴 카드

### 패턴 카드 형식

```
패턴명 / 유형 / 마일스톤
[일반 형태]  [학습 항목]  [발동 조건]  [역이용]  [예고]
[대응법]  [보상]  [대사]  [공정성 체크]  [구현 메모]
```

---

### 4.1 세 번째 칼날 ⭐ M1 핵심

| 항목 | 내용 |
|---|---|
| 유형 | 안전하다고 믿는 순간 깨기 / 공격 습관 |
| 마일스톤 | M1 (3막 확장은 M2) |
| 일반 형태 | 보스가 큰 공격 후 숨 고르기 → 빈틈 |
| 학습 항목 | 빈틈마다 플레이어의 **콤보 길이 분포** (망각 포함) |
| 발동 조건 | 빈틈 관찰 4회 이상 AND 3타까지 칠 확률 75% 이상 `[추정]` |
| 역이용 | "플레이어가 마지막으로 칠 확률이 가장 높은 타"를 보스가 패링 |
| 첫 발동 | **확정 발생, 예고 없음, 체력 최소 1 보장** (학습의 순간) |
| 이후 발동 | 확률 상한 50%, 막이 진행될수록 예고 축소 (2막: 2타 후 보스의 무기 쪽 손이 살짝 빛남 → 3막: 시선만) |
| 대응법 | 콤보 길이 바꾸기 / 2타에서 끊기 / 미세한 예고 읽기 |
| 보상 | 보스가 헛짚으면 빈틈 2배 + 받는 피해 증가 |
| 2차 학습 | 플레이어가 계속 2타에서 끊으면 → 패링하는 타를 2타로 이동. 결국 **콤보 길이를 바꾸는 플레이어가 가장 강함** |

**대사**

| 상황 | 대사 |
|---|---|
| 첫 패링 | "…이런 식으로 막던가?" |
| 재발동 | "세 번째. 늘 세 번째였지." |
| 헛짚음 | "……배웠군." |
| NPC (헛짚음) | "지금이야! 저 녀석 헛짚었어!" |

**3막 확장: 방패 탈취** → §4.5

**공정성 체크**: ✅ 첫 피격 생존 ✅ 대응법 있음 ✅ 적응하면 보상 ✅ 확률 상한 ✅ 망각

**구현 메모**

| 기능 | 원리 |
|---|---|
| 콤보 길이 기록 | 빈틈 하나당 친 타수를 세서 분포 저장 (Lv1) |
| 패링할 타 결정 | "k타까지 칠 확률"이 가장 높고 기준을 넘는 타 |
| 보스 패링 | 보스 FSM에 "반격 자세" 상태 → 공격이 오면 패링 성공, 안 오면 헛짚음 상태 |
| 이벤트 | `bossParrySuccess`, `bossParryWhiff` |

### 4.2 중앙 내려찍기 ⭐ M1

| 항목 | 내용 |
|---|---|
| 유형 | 방향 / 궤적 (잔상 시스템 첫 적용) |
| 마일스톤 | M1 |
| 일반 형태 | 검을 치켜들고 기 모으기 → 맵 중앙 세로 띠가 빨갛게 빛남 → 2초 후 피해 |
| 선택지 | 왼쪽 / 오른쪽 / 관통 대시 / 패링 (**정답이 하나가 아니어야 학습이 의미 있음**) |
| 학습 항목 | 예고 시작부터의 회피 궤적 |
| 발동 조건 | 같은 패턴 3회 이상 관찰 AND 회피 방향 한쪽 비율 65% 이상 `[추정]` |
| 역이용 | 멈칫 → 시선 → **잔상이 내 습관대로 움직임** → 중앙 + 잔상 도착 지점에 피해 |
| 예고 | §3.1 막별 예고 축소 적용 |
| 대응법 | 잔상과 다른 쪽으로 / 관통 대시 / 패링 |
| 보상 | 예측이 빗나가면 보스 경직 |

**대사**: 멈칫 시 "…오른쪽." (학습한 방향을 언급)

**공정성 체크**: ✅ 선택지 복수 ✅ 예고 진실 ✅ 해결책 남음 ✅ 빗나가면 빈틈

> 설계 경위: 처음 안은 "왼쪽 절반 공격 → 오른쪽으로 피함"이었으나, 오른쪽밖에 갈 곳이 없으면 습관이 아니라 규칙이므로 중앙 공격으로 바꿔 선택지를 열었다.

### 4.3 암반 엄폐 — M2

| 항목 | 내용 |
|---|---|
| 유형 | 안전하다고 믿는 순간 깨기 / 공간 |
| 마일스톤 | M2 (암반 낙하·파괴, 엄폐 판정, 보스 이동이 필요해 M1보다 무거움) |
| 일반 형태 | 암반 여러 개가 떨어짐 → 보스가 큰 공격 준비 → 암반 뒤에 숨어서 피함 |
| 학습 항목 | 고른 암반, 도착 경로·시간, 숨는 위치, **공격 후 나온 방향** |

**단계별 역이용 (채택: ④, ③)**

| 단계 | 학습 | 역이용 | 채택 |
|---|---|---|---|
| ① 어느 암반 | 즐겨 숨는 암반 | 그 암반을 먼저 부숨 | 후보 |
| ② 경로 | 잔상이 평소 경로로 달려감 | 경로에 투사체 | 후보 |
| ③ 서는 위치 | 엄폐 각도 | **보스가 자리를 옮겨 엄폐가 안 되는 각도를 잡음** | ✅ |
| ④ 나오는 방향 | 공격 후 고개를 내미는 쪽 | **출구 쪽에서 기다렸다가 공격** | ✅ |
| ⑤ 숨는 행동 | 숨으러 달려가는 습관 | 가짜 큰 공격 → 등 보인 플레이어 기습 (드물게) | 후보 |

**공정성 체크**: ✅ 다른 암반·경로 남음 ✅ 보스 이동·응시가 보임 ✅ 출구 반대로 나오면 등 뒤 기회

**구현 메모**: 보스→플레이어 선이 암반에 막히는지 레이캐스트로 판정. 보스의 각도 탐색도 같은 계산. 잔상 녹화 구간을 "예고 시작 → 공격 종료 후 1~2초"로 늘려 나오는 동작까지 기록.

### 4.4 탄막 페이즈 — M2~M3

| 항목 | 내용 |
|---|---|
| 유형 | 위치 분포 / 궤적 |
| 마일스톤 | M2 히트맵 탄막 / M3 잔상 탄막 + 스펠 이름 |
| 위치 | 3막 중반, 보스가 거리를 벌리고 탄막 페이즈로 전환 (근접전과 리듬 전환) |

**학습 항목**

| 학습 | 보스의 대응 |
|---|---|
| 위치 습관 (주로 머무는 영역) | 그 영역에 탄을 더 배치 |
| 이동 습관 (예: 시계 방향 회전) | 이동할 곳을 미리 조준 |
| 틈 선택 (탄 벽의 구멍) | 그 구멍을 막고 다른 곳을 엶 |
| 회피 스타일 (조금씩 / 크게) | 상성이 나쁜 탄막 선택 |
| 반응 속도 | 탄 속도를 아슬아슬하게 (상한 있음) |

**연출**

| 연출 | 내용 |
|---|---|
| 히트맵 (M2) | 탄막 전 바닥에 붉은 안개 = 내가 주로 있던 곳. 탄이 그 분포대로 쏟아짐 |
| 잔상 탄막 (M3) | 이전 판들의 회피 궤적이 잔상 여러 개로 재생 → 보스가 잔상들을 조준 → 잔상이 깨짐. "보스가 과거의 나를 쏜다" |
| 스펠 이름 (M3) | 탄막 이름 = 내 습관. 「스펠: 왼쪽 아래에 숨는 자」 |

**공정성 체크**: ✅ 안전 경로 자동 검사(없으면 탄 제거) ✅ 밀도 상한 ✅ 안개·잔상이 먼저 ✅ 히트맵 오염으로 역이용 가능

**구현 메모**: 위치 히트맵 = 격자(예: 16×9) 체류 시간 + 망각 (Lv1의 2차원 버전). 발사 위치는 히트맵 비례 확률 샘플링. 탄 수백 발은 오브젝트 풀링.

### 4.5 방패 탈취 → 거울 페이즈 — M2 (클라이맥스)

세 번째 칼날의 3막 확장. 2막의 복선을 3막에서 회수한다.

| 단계 | 일어나는 일 | 대사 |
|---|---|---|
| 2막 | 3타 패링 + 피격 (방패 유지) — 복선 | "…이런 식으로 막던가?" |
| 3막 | 3타 패링 + **패링 의존도가 높으면** 방패 탈취 | "이제… 이건 내 거다." |

| 항목 | 내용 |
|---|---|
| 조건 | 3막 + 3타 패링 성공 + 플레이어의 패링 의존도 높음 (패링을 별로 안 쓴 플레이어는 잃지 않음 → 개인화의 증거) |
| 연출 | 방패가 부서져 조각이 보스에게 흡수 → 보스 손에 내 방패의 실루엣 |
| 벌 | 한 판 1회, **탈취 시 피해는 줄임** (한 사건에 벌은 하나) |
| 탈취 중 플레이어 | 대시·이동 유지 (방어 수단 동시 박탈 금지) |
| 탈취 중 보스 | 패링 전용 공격 사용 안 함. 플레이어 공격을 **플레이어의 패링 타이밍 분포 그대로** 패링 (거울) |
| 회복 | 내 습관과 다른 박자로 때려 보스 패링을 깨뜨림 / 또는 일정 시간 경과 (안전장치) |
| 대사 | 회복 시 "…돌려주지." / NPC "저 녀석, 네 타이밍으로 막고 있어! 반 박자 늦춰!" |

**거울 페이즈 (최종)**: 보스가 내 전투 방식을 따라 함 — 선호 대시 방향, 콤보 길이, 포션 마시는 체력, 녹화 궤적. 공략 = "내 약점은 내가 안다".

**기타 봉인 대응 (강도별 후보)**

| 강도 | 패링 | 대시 |
|---|---|---|
| 약 | 패링에 강한 자세 (막혀도 경직 없음) | 자주 가는 도착 지점에 함정 |
| 중 | 패링 판정 시간 단축 | **자주 쓰는 방향만** 불길로 차단 |
| 강 | 방패 탈취 (위) | 감속 장판 (완전 봉인은 하지 않음) |

## 5. 후보 패턴 목록

M2 이후 필요할 때 꺼내 쓴다.

| 유형 | 학습 | 역이용 |
|---|---|---|
| 안전한 순간 | 변신·페이즈 전환 중 포션 | 변신을 끊고 기습 |
| 안전한 순간 | 패링 성공 후 경직 중 타수 | 경직을 줄여 욕심낸 마지막 타에 반격 |
| 안전한 순간 | 항상 보스 등 뒤로 감 | 등 뒤 공격 추가 |
| 공격 습관 | 일정한 공격 리듬 | 박자 사이에 끼어드는 공격 |
| 공격 습관 | 때리고 바로 대시로 빠짐 | 대시 도착 지점 공격 |
| 거리·위치 | 선호 거리 (근접 / 견제) | 근접엔 충격파, 견제엔 돌진 |
| 거리·위치 | 벽 근처에서 싸움 | 벽으로 몰아붙이기 |
| 거리·위치 | 위기 때 같은 구석으로 도망 | 그 구석을 먼저 차단 |
| 위기 반응 | 피격 직후 당황 대시 / 즉시 반격 | 도착 지점 공격 / 반격 예상 패링 |
| 위기 반응 | 스태미나 부족 시 후퇴 | 바닥날 때 압박 |
| 재도전 | 전투 시작 직후 행동 | 시작과 동시에 그 위치 공격 ("또 왔군.") |
| 재도전 | 반복해서 죽는 패턴 | 그 패턴 빈도 증가 |
| 2차 학습 | 멈칫을 보면 항상 반대로 피함 | 멈칫한 척하고 원래 패턴 (이중 블러핑) |
| 2차 학습 | 읽히면 바로 습관을 바꾸는 속도 | 바뀐 습관을 미리 예측 |
