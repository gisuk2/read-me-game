## 1. 설계 목표

| 목표 | 설명 |
|---|---|
| **어렵지만 공정하게** | 쉬운 게임보다 어려운 게임. 단, 모든 피격에는 "내가 무엇을 잘못했는지"가 보여야 한다 |
| **공격성에 보상** | 패턴을 보고 빈틈에만 때리는 수동적 전투가 되지 않게, 먼저 움직이고 압박하는 플레이를 보상한다 |
| **숙달 가능** | 일반 패턴은 일정해서 몸으로 익힐 수 있어야 한다 |
| **학습이 빛나게** | 일반 패턴이 단단해야 학습 변칙 패턴이 충격으로 다가온다 |

## 3. 자세 게이지 (보스)

패링을 방어이자 공격으로 만들고, 기다리는 플레이를 손해로 만드는 핵심 장치.

```
[증가]  패링 성공 ········ 크게
        공격 적중 ········ 조금
        연속 적중 ········ 점점 더 많이
[감소]  보스가 공격받지 않는 동안 서서히 회복
[가득]  자세 붕괴 → 보스가 무너짐 → 큰 빈틈 (치명타 기회)
```

| 설계 포인트 | 내용 |
|---|---|
| 압박의 이유 | 가만히 있으면 게이지가 회복되므로, 계속 압박해야 이긴다 |
| 패링 중심 전투와 연결 | 패링이 가장 큰 게이지 수단 → 보스가 패링 습관을 학습할 동기가 자연스러움 |
| 학습과의 연결 | 플레이어가 게이지를 채우는 방식(패링 위주 / 공격 위주)도 학습 데이터가 됨 |

> 참고: 세키로의 "체간" 시스템과 같은 발상.

## 4. 빈틈의 종류

빈틈이 "패턴 끝"에만 있으면 차례 지키기 전투가 된다. 같은 패턴 안에서도 공격 기회를 여러 개 둔다.

| 빈틈 | 내용 | 요구하는 실력 |
|---|---|---|
| 패턴 후 경직 | 큰 공격 뒤의 빈틈 (기본) | 패턴 읽기 |
| 헛손질 응징 | 보스 공격이 닿지 않는 거리로 유도 → 허공을 칠 때 파고들기 | 거리 조절 |
| 연타 사이 끼어들기 | 연속 공격 사이의 짧은 틈 | 리듬 읽기 |
| 준비 동작 끊기 | 일부 공격은 준비 중 적중 시 끊김 (끊기지 않는 공격도 섞음) | 판단력 |
| 이동 중 등 뒤 | 보스가 자리를 잡으며 이동할 때 | 위치 선정 |
| 자세 붕괴 | 자세 게이지 가득 | 압박 유지 |
| 헛짚음 | 보스의 예측 공격이 빗나감 (학습 역이용 실패) | 습관 바꾸기 |

## 5. 보스 일반 패턴

### 5.1 구성

| 분류 | 패턴 (예시) | 역할 |
|---|---|---|
| 이동 | 걸어서 접근, 옆으로 돌기, 뒤로 물러나기, 돌진 접근 | 거리 조절, 긴장감 |
| 기본 공격 | 휘두르기(1~2연타), 찌르기, 회전 베기, 점프 내려찍기 | 숙달 대상 |
| 탐색 | 거리를 재며 옆으로 돌기, 자세 잡기 | 누가 먼저 움직이느냐의 싸움 |
| 쉬는 동작 | 숨 고르기, 도발 | 플레이어의 공격 기회, 숨 돌릴 틈 |

규모 목표 `[추정]`: **일반 공격 6~8개 (분기 포함)**. 다양함은 개수가 아니라 분기에서 만든다.

### 5.2 분기와 지연

```
휘두르기 ─┬─ 끝 (빈틈)
          ├─ 찌르기로 연결
          └─ 지연 후 회전 베기   ← 같은 시작, 다른 결말
```

- **분기**: 시작이 같아도 결말이 다르면 매번 읽어야 한다.
- **지연 공격**: 박자를 외우는 게 아니라 보고 반응하게 만든다.

### 5.3 일반 패턴은 "질문"이다

```
일반 패턴     = 질문 (관찰, 데이터 수집)
학습 변칙 패턴 = 답 ("너는 이렇게 하더라")
```

같은 질문을 던져야 답을 비교할 수 있다. 그래서 일반 패턴의 예고·판정은 일정해야 한다.

## 6. 적응의 3단계

| 단계 | 대상 | 보이는가 | 예시 |
|---|---|---|---|
| **고정** | 일반 공격의 예고 시간, 판정 범위, 속도 | — | 찌르기는 항상 같은 예고 후 직선 판정 |
| **미세 적응** | 일반 공격 선택 빈도, 거리 조절, 접근 각도 | 전투 중엔 거의 ❌ (사망 리포트에서 공개) | 잘 못 피하는 찌르기를 조금 더 자주 |
| **가시적 변칙** | 학습 변칙 패턴 ([보스 패턴](boss-patterns.md)) | ✅ | 세 번째 칼날, 잔상 내려찍기 |

### 6.1 고정: 절대 바꾸지 않는 것

일반 공격의 예고·판정·속도가 바뀌면 플레이어는 학습이 아니라 "조작이 이상하다"고 느낀다.

### 6.2 미세 적응 (밴딧)

| 학습 | 적응 | 제한 |
|---|---|---|
| 어떤 일반 공격에 자주 맞는지 | 그 공격의 선택 가중치를 올림 | 기본값의 0.8~1.3배 |
| 어떤 거리에서 플레이어가 약한지 | 그 거리를 유지하려 이동 | 집요하게 따라붙지 않게 |
| 플레이어가 돌아 들어오는 방향 | 그쪽으로 몸을 미리 틀어둠 | 회전 속도 제한 |

```
일반 공격 선택 = 가중치 있는 무작위 선택
적중하면(보상) → 가중치를 조금 올림 → 단, 0.8~1.3배 범위 안에서만
```

- 이것은 로드맵 Lv3 **멀티암드 밴딧**의 적용처다.
- 범위 제한이 없으면 한 공격만 반복하는 퇴화 상태가 된다. 제한은 필수.
- 사망 리포트에서 공개: *"보스는 당신이 약한 '찌르기'를 32% 더 자주 사용했습니다."*

### 6.3 변칙 빈도 가이드 `[추정]`

| 범위 | 빈도 |
|---|---|
| 보스 행동의 대부분 | 고정된 일반 패턴 (미세 적응 포함) |
| 가시적 변칙 | 도전 1회당 2~4번 |
| 클라이맥스 사건 (방패 탈취 → 거울) | 3막에서 1번 |

## 7. 난이도 설계

| 요소 | 내용 |
|---|---|
| 양쪽 다 아프게 | 한 번의 실수와 한 번의 성공이 모두 무거움 |
| 욕심 응징 | 빈틈에 너무 많이 때리면 반격 (→ 세 번째 칼날) |
| 자원 제한 | 스태미나·포션 제한 |
| 빠르지만 읽을 수 있는 예고 | 반응 시간은 짧게, 예고는 명확하게 |
| 지연과 분기 | 외우기가 아니라 보고 반응 |
| **학습하는 보스** | 외운 만큼 보스도 나를 외운다 — 이 게임만의 난이도 상승 장치 |

목표 지표 `[추정]`: 평균 **5~10회 도전에 클리어**. 플레이 로그로 측정·조정.

## 8. 공정성 원칙

모든 학습 변칙 패턴은 아래 원칙을 통과해야 한다. ([보스 패턴](boss-patterns.md)의 패턴 카드마다 체크)

| # | 원칙 | 내용 |
|---|---|---|
| 1 | **선택지가 있어야 학습이다** | 정답이 하나뿐인 상황의 행동은 습관이 아니라 규칙. 안전한 선택지를 여러 개 연다 |
| 2 | **예고는 진실이어야 한다** | 보스는 플레이어를 읽어도 되지만, 예고 시스템이 거짓말을 하면 안 된다 |
| 3 | **항상 해결책이 남아 있다** | 다른 경로, 패링, 관통 대시 등 최소 하나는 유효 |
| 4 | **읽힌 쪽에도 기회가 있다** | 보스의 예측이 빗나가면 평소보다 큰 빈틈 |
| 5 | **확률 상한** | 역이용 발동 확률에 상한 (예: 50~60%). 같은 대응만 반복하지 않음 |
| 6 | **망각** | 최근 행동에 가중치. 습관을 바꾸면 보스도 따라 바뀐다 |
| 7 | **한 사건에 벌은 하나** | 피해가 크면 빼앗지 않고, 빼앗으면 피해를 줄인다 |
| 8 | **방어 수단을 동시에 다 빼앗지 않는다** | 패링을 막으면 대시는 남긴다 |
| 9 | **죽음은 스토리 장치로 쓸 수 있다** | 단, 재시작은 짧게(체크포인트) 하고 매번 힌트를 더 준다. ([스토리 5장](story.md#5-전환점-설계-거역하는-순간)) *v0.2에서 "첫 학습 순간은 죽지 않는다"를 대체* |
| 10 | **역이용당할 수 있는 보스** | 학습을 거꾸로 이용(가짜 습관 심기)하는 공략이 가능해야 한다 |
