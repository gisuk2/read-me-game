## 1. 주제

> **"가르쳐 놓고, 빼앗는다."**

튜토리얼이 가르친 정석을 보스가 학습해 역이용한다. 예고도, 가이드도, 플레이어의 기술도 같은 원리로 하나씩 사라지고, 마지막에 남는 건 "나 자신에 대한 이해"다.

---

## 2. 3막 구조

| 막 | 이름 | 보스 | 가이드 NPC | 플레이어의 경험 |
|---|---|---|---|---|
| 1막 | 가르침 | 정직한 예고, 일반 패턴 | **선생님**: 정석을 알려줌 | 평범한 튜토리얼 보스전 |
| 2막 | 관찰 | 멈칫·시선·잔상 등장, 세 번째 칼날 | **함께 놀람 → 분석 파트너** | "보스가 나를 보고 있다" |
| 3막 | 역이용 | 예고 축소, 탄막 페이즈, 방패 탈취 | **조언이 통하지 않음** | "보스가 나를 공략한다" |
| 최종 | 거울 | 내 방식으로 싸움 | 침묵 또는 마지막 한마디 | "내 약점은 내가 안다" |

데이터가 없을 때 보스는 튜토리얼 정석대로 예상하고 행동한다(백오프의 4순위 기본값). 데이터가 쌓이며 "나를 아는 보스"로 바뀐다. **기술 구조와 3막 구성이 같은 흐름이다.**

---

## 3. 가이드 NPC

"튜토리얼 그 자체"를 캐릭터로 만든 존재. NPC가 보스에게 배신당하는 순간 "보스가 정석을 넘어섰다"는 사실이 숫자나 UI 없이 감정으로 전달된다.

### 3.1 막별 역할

| 시점 | 역할 | 대사 예시 |
|---|---|---|
| 1막 | 선생님 | "빨간 곳을 피해서 옆으로!" / "빈틈이야, 지금 공격해!" |
| 첫 배신 | 함께 놀람 | "어…? 저건 내가 아는 패턴이 아니야!" |
| 2막 | 분석 파트너: 새 규칙을 가르침 | "방금 저 녀석, 멈칫했어. 너를 보고 있었어." / "멈칫하면… 네가 가려는 쪽을 노리는 거야!" / "저 녀석… 네가 하는 대로 배워." |
| 3막 | 조언이 통하지 않음 | "내 조언대로 움직이는 걸… 저 녀석이 배웠어. 이제 네 판단을 믿어." |

3막의 핵심: **보스가 NPC의 조언까지 학습한다.** 플레이어가 NPC 말을 따르는 습관 자체가 데이터이기 때문이다.

### 3.2 첫 배신 장면

```
NPC: "알려준 대로 피해요!" → 플레이어가 따름 → 역이용 공격 피격 → NPC: "어…?!"
```

- 이 피격은 **체력 최소 1 보장** (따랐는데 죽으면 불쾌함만 남음)
- 벌이 아니라 이야기의 전환점으로 연출

### 3.3 NPC 정체

| 항목 | 상태 |
|---|---|
| 이름·외형·말투 | 미정 |
| 반전 아이디어 | **보류**: NPC가 사실 보스의 데이터 수집 장치였다 (친절한 튜토리얼 = 관찰 수단). 주제와 맞물리지만 이야기 비중이 커지므로 M2 이후 판단 |

## 4. 대사 원칙

| 원칙 | 내용 |
|---|---|
| 전투 중엔 짧게 | 한 줄, 10자 안팎 ("오른쪽!", "어…?!", "멈칫했어!") |
| 긴 설명은 틈에 | 공격 사이 휴식, 사망 화면 |
| **구체적으로** | 일반론("네 수는 다 보인다") ❌ → 회차·수치("세 번째 도전에서도… 넌 왼쪽이었지.") ✅ |
| LLM 미사용 | 미리 쓴 대사 템플릿 + 학습값 삽입. API 비용 0원 원칙 유지 |

### 4.1 보스 대사 템플릿 예시

| 트리거 | 템플릿 |
|---|---|
| 방향 역이용 | "…{방향}." |
| 재도전 기억 | "{N}번째 도전에서도… 넌 {방향}이었지." |
| 포션 저격 | "포션. 또 체력 {X}%에서군." |
| 콤보 패링 | "{K}번째. 늘 {K}번째였지." |
| 헛짚음 | "……배웠군." |
| 방패 탈취 / 회복 | "이제… 이건 내 거다." / "…돌려주지." |
| 전투 시작 습관 | "또 왔군." |

## 5. 학습 가시화 장치 종합

| 장치 | 언제 | 무엇을 보여주나 |
|---|---|---|
| 멈칫 + 시선 | 역이용 직전 | "지금 너를 읽었다" |
| 잔상 | 역이용 직전 | 보스가 예측한 나 (녹화된 실제 궤적) |
| 구체적 대사 | 역이용 순간 | 나만의 기록 |
| NPC 반응 | 역이용 순간 / 헛짚음 | 사건이 우연이 아님 |
| 사망 리포트 | 사망 시 | 보스가 알아낸 것 전체 |
| 거울 페이즈 | 최종 | 보스가 나처럼 싸움 |

## 6. 사망 리포트

```
┌────────────── YOU DIED ──────────────┐
│  보스가 당신에 대해 알아낸 것          │
│  ▸ 대시 방향   왼쪽 ████████░░ 72%    │
│  ▸ 체력 30% 이하 → 포션  89%          │
│  ▸ 빈틈에서 3타까지  81%              │
│  ▸ 보스는 '찌르기'를 32% 더 자주 사용  │
│                                       │
│  [보스의 예측 vs 실제 움직임 재생]      │
│  예측 정확도: 64%                      │
│                                       │
│  NPC: "저 녀석이 알아낸 게 이거야…"    │
└───────────────────────────────────────┘
```

| 요소 | 목적 |
|---|---|
| 학습 수치 | 다음 도전의 공략 동기 ("다음엔 저걸 역이용해야지") |
| 미세 적응 공개 | 전투 중 안 보이던 적응을 뒤늦게 공개 ("어쩐지 찌르기가 많더라…") |
| 예측 vs 실제 재생 | 잔상 시스템의 증거 |
| NPC 낭독 | 캐릭터와 시스템 연결 |

구현: HTML/CSS 오버레이 ([계획서 §5](../00_project-plan.md#5-시스템-구조)).

## 7. 측정 (M1 재미 검증)

학습이 실제로 느껴지는지는 만들어 봐야 안다. 테스터에게 묻는다.

| 질문 | 목적 |
|---|---|
| 보스가 당신을 학습했다고 느꼈나요? | 핵심 경험 검증 |
| 그렇게 느낀 근거는 무엇인가요? | 어떤 장치가 효과적인지 |
| 불공평하다고 느낀 순간이 있었나요? | 공정성 검증 |
| 다시 도전하고 싶었나요? | 재도전 동기 |

일부 플레이어는 여전히 스크립트라고 느낄 수 있다. 완전히 없앨 수 없으므로 측정하고 개선한다.
