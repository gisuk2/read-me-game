## 1. 목표

> 변칙 패턴이 "지난번과 다른 공격"으로 끝나지 않고, **"보스가 나를 학습했다"**로 느껴지게 한다.

핵심은 인과가 눈에 보이는 것이다.

```
내가 한 행동  →  보스가 그걸 봤다 (증거)  →  그래서 이렇게 나온다 (대응)
```

## 2. 원칙

| 원칙 | 내용 |
|---|---|
| 증거 먼저, 처벌 나중 | "읽혔다"는 증거를 맞기 직전·직후에 보여준다. 그래야 억울함이 아니라 소름이 된다 |
| 숫자는 진짜로 | 로그·리포트의 수치는 실제 기록에서 나온다. 지어낸 숫자는 몇 판 만에 들킨다 |
| 습관을 깨면 보상 | 학습이 빗나가면 보스가 멈칫한다 → 역으로 속이는 재미 |
| 막에 따라 강도를 올림 | 처음엔 은근하게, 뒤로 갈수록 노골적으로 (§4) |

## 3. 보여주는 방법

| # | 경로 | 방법 | 내용 | 우선 |
|---|---|---|---|---|
| ① | 화면 기록 | 잔상 | 지난번 내 움직임을 반투명 재생 ([보스 패턴 §2](boss-patterns.md#2-잔상-시스템-대표-시스템)) | ⭐ |
| ② | 화면 기록 | 바닥 열지도 | 자주 서 있던 자리가 바닥에 희미하게 물들고 보스가 거기를 노림 | |
| ③ | 화면 기록 | 사망 흔적 | 죽은 자리에 흔적, 다음 판에 그 자리를 노림 | |
| ④ | 보스 몸짓 | 예측 조준 | 내가 아직 안 간 곳을 보스가 먼저 쳐다봄 | ⭐ |
| ⑤ | 보스 몸짓 | 미끼 | 시작 자세만 하고 멈춰서 내 습관적 반응을 기다렸다가 응징 | |
| ⑥ | 보스 몸짓 | 흉내 | 보스가 내 콤보 박자·회피 방향을 그대로 씀 (거울 복선) | |
| ⑦ | 색·소리 | 내 색깔 | 학습으로 만든 공격은 무기가 **플레이어 색**으로 빛남 = "너로 만든 공격" | ⭐ |
| ⑧ | 색·소리 | 전용 효과음 | 학습 공격 직전 데이터 처리음 | |
| ⑨ | 글자 | 분석 로그 | `[ANALYSIS] 후방 회피 87% (13/15)` → `[COUNTER] 적용` | ⭐ |
| ⑩ | 글자 | 패턴 이름 | `COUNTER: TESTER-0222 / 후방회피` | |
| ⑪ | 글자 | 사망 리포트 | "이 상황에서 7번 중 6번 뒤로 피했습니다" + 다시보기 | |
| ⑫ | 이야기 | 헬퍼 반응 | "어…? 이건 제 데이터에 없는 패턴인데요" | |
| ⑬ | 반대 방향 | 멈칫 | 습관을 바꾸면 보스가 굳고 `[ERROR] 예측 실패` | ⭐ |
| ⑭ | 반대 방향 | 점점 정확해짐 | 첫 대응은 살짝 빗나가고 반복할수록 정확해짐 | |
| ⑮ | 헬퍼 카드 | **카드 노이즈** | 변칙 패턴이 나올 때마다, 헬퍼의 그림 카드(§6.1)에서 더 이상 맞지 않는 칸(무기·패턴 이름·대응법)이 노이즈로 깨짐 = "헬퍼의 정석이 무너졌다"는 증거 | ⭐ |

⭐ 조합(①④⑦⑨⑬) = 증거 + 나를 위한 공격 + 진짜 숫자 + 다시 이길 방법.

> 변경: [보스 패턴 §3](boss-patterns.md#3-역이용-예고-설계)의 "전용 색 예고는 쓰지 않는다"를 ⑦로 일부 수정. 색은 **공격 범위 예고가 아니라 "이 공격은 학습으로 만들어졌다"는 표식**으로만 쓴다. 범위는 여전히 몸짓·잔상으로 읽는다.

## 4. 막별 강도

| 막 | 학습 표시 |
|---|---|
| 1막 | 학습 없음. 사망 기록만 쌓임 (§5) |
| 각성 후 | 몸짓과 색만 (④⑦), 은근하게 |
| 3막 | 로그·잔상·열지도로 노골적으로 (①②⑨) |
| 반전 | 전체 기록 공개. 보스가 사망 지도에 빨간 동그라미를 쳐 둔 화면 |

## 5. 사망 시스템

### 5.1 한 방 사망

| 항목 | 결정 |
|---|---|
| 사망 | **모든 공격 한 방** (1막부터) |
| 이유 | 죽음이 많아야 데이터가 쌓이고, 사망 지도가 의미를 가지며, 1막 데이터로 각성 직후 변칙이 가능 |
| 플레이어 체력 바 | 없앰 (스태미나만 남음) |
| 포션·보호막 | **없음**. 빠른 부활(§5.2)이 실수에 대한 보험 역할 |
| 보스 공격 피해량 | 설정에 남겨 둠 (쉬운 모드 등 대비) |
| 재시작 | 빠른 부활 (§5.2) |
| 공정성 | 모든 공격은 몸동작으로 읽혀야 함 → 보스 몸·무기 작업(2c-1)이 전제 |

### 5.2 빠른 부활과 재시작 지점

```
쓰러짐 → 0.45초 멈춤 + "휘두르기 (대검)에 맞음 · 남은 재시도 3"
       → 직전 패턴이 시작되기 전으로 되감기 (카타나 제로처럼)
같은 구간에서 5번째 → 사망 지도 → 체크포인트(보스 체력 단계)에서 다시
```

| 규칙 | 내용 |
|---|---|
| 되감기 지점 | 보스가 새 패턴(연속기의 첫 타)을 시작하는 순간의 플레이어·보스 상태 전체 |
| 되감는 것 | 위치·스태미나·상태 + **보스 체력·자세 게이지·무기까지** (그 패턴 동안 넣은 피해도 되돌림 → 한 패턴을 확실히 넘겨야 함) |
| 재시도 | 같은 구간에서 5번. 새 체크포인트가 저장되면 다시 5번 (화면 왼쪽 위 ●●●○○) |
| 5번째 사망 | 사망 지도를 보여준 뒤 체크포인트에서 다시 시작 |
| 구간 끝 | 튜토리얼 방식 = 처음부터 / 체크포인트 방식 = 보스 체력 5단계 (테스트 중엔 M 키로 전환) |

| 체크포인트 규칙 | 내용 |
|---|---|
| 표시 | 보스 체력 바를 5칸으로 나눔. 한 칸을 깎으면 "저장됨" (시뮬레이션 스냅샷) |
| 사망 시 | 마지막 저장 칸의 맨 위 체력으로 복귀. **보스의 학습은 유지** |
| 의미 | 죽음의 대가가 시간이 아니라 **정보**. 죽을수록 보스가 나를 알게 됨 |
| 페이즈 기믹 | 칸 경계(예: 60%, 20%)에서 시작 → 시작 시점이 곧 저장 지점 |
| 마지막 칸 | 저장 없이 끝까지 (검토) |

### 5.3 사망 기록

| 항목 | 내용 |
|---|---|
| 기록 내용 | 위치, 죽인 공격, 패턴 카테고리, 페이즈, 사망 직전 1초 움직임, 시각 |
| 저장 | 브라우저 저장소 (껐다 켜도 유지, 실패해도 게임은 진행) |
| 용도 | 플레이어: 사망 지도 / 보스: 학습 데이터 (**같은 데이터를 양쪽이 본다**) |

### 5.4 사망 지도 UI

| 요소 | 내용 |
|---|---|
| 지도 | 경기장 축소 지도에 사망 위치 X, 색 = 죽인 공격 |
| 직전 움직임 | 사망 직전 1초 이동을 화살표로 |
| 통계 한 줄 | "최다 사망: 휩쓸기 12회 · 주 위치: 좌상단" |
| 표시 시점 | 5번째 사망 때만 (빠른 부활 때는 짧은 메시지만). Tab으로 크게 보기 |
| 표면 설정 | "QA 텔레메트리 리포트 — 버그 제보용 사망 데이터 수집" |
| 반전 | 같은 화면을 보스도 보고 있었다 |

## 6. 패턴 안내와 강제 사망 연출

### 6.1 헬퍼가 패턴을 알려준다

| 패턴 | 언제 | 방식 |
|---|---|---|
| 일반·강 | **처음 나올 때** | 0.7초 느려지며 헬퍼 말풍선 한 줄 (예: "창이에요! 옆으로! 세 번째는 늦게 와요!"). 패턴마다 한 번 |
| 처음 접속 | 전투 전 | 헬퍼 인사 세 줄만 (긴 설명 없음) |
| 다시 보기 | 일시정지 메뉴 "패턴 안내" | **무기별 그림 카드 6장**: 무기 아이콘 + 패턴 이름 + 대응법 꼬리표 (예: `옆으로` `3번째 늦음`). 칸마다 열쇠가 있어 ⑮ 노이즈를 칸 단위로 적용 |
| 페이즈 | **페이즈가 시작되는 순간** | 화면이 맵 전체로 전환 → 멈춤 → 헬퍼가 기믹과 파훼법 설명 |

> 폐기: "미확인 → 관측 예고" (처음 보는 패턴은 예고 없이 몸동작만, 겪고 나면 예고가 열림). 튜토리얼에서 많이 죽게 해 데이터를 쌓으려던 장치였으나, 헬퍼 브리핑 + 빠른 부활로 대체. 놀라는 순간은 아래 페이즈 장면이 맡는다.

### 6.2 강제 사망 연출 → 2막의 시작

```
첫 페이즈 패턴 시작 → 화면 전환·정지 → 헬퍼가 파훼법 설명 + "왼쪽으로 움직이세요!"
(← 표시, 다른 키 잠김, → 키는 회색 자물쇠) → ← 입력 → 시간 재개 → 사망
→ 헬퍼 "어…? 분명 왼쪽이 맞는데…" → 2막 시작 (보스는 헬퍼의 파훼법을 이미 알고 있었다)
```

| 역할 | 내용 |
|---|---|
| 2막의 문 | 헬퍼 말을 따랐더니 죽었다 → "헬퍼 말대로 하면 죽는다"의 시작 |
| 회수 | 전환점에서 같은 정지 화면이 다시 나오고, 이번엔 → 도 눌림 → [스토리 §5.1](story.md#51-수미상관-튜토리얼의-정지-화면) |
| 제한 | 한 번만, 2회차부터 건너뛰기 |
